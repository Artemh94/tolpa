Как запустить MiroFish — толпу из ИИ-людей

Кидаешь новость или идею — тысячи ИИ-жителей её обсуждают, на выходе отчёт. Код открытый и бесплатный, платишь только за токены нейросети. Сверено с README проекта, октябрь 2026.

MiroFish на GitHub
  1. 01

    Открой Claude Code в пустой папке

    Подойдёт и Cursor. Python, Node и зависимости руками ставить не нужно — это сделает Клод.

  2. 02

    Вставь ему этот промпт

    Склонируй https://github.com/666ghj/MiroFish и запусти по README. Поставь всё, что нужно: Node 18+, Python 3.11–3.12, uv. Создай .env из .env.example, ключи спроси у меня. Когда запустится — скажи, какой адрес открыть.
  3. 03

    Возьми два ключа

    • Нейросеть. Подойдёт любой API в формате OpenAI. Авторы советуют qwen-plus на Alibaba Bailian. В .env это LLM_API_KEY, LLM_BASE_URL, LLM_MODEL_NAME — Клод подскажет, что куда.
    • Память жителей. Zep Cloud — есть бесплатная квота на месяц. В .env это ZEP_API_KEY.
  4. 04

    Открой localhost:3000

    Если интерфейс на китайском — переключи язык на английский.

  5. 05

    Запусти первую симуляцию

    Загрузи «зерно»: новость, отчёт, описание продукта. Вопрос пиши обычными словами: «Как люди отреагируют на подписку за 990 ₽?»

    Первые прогоны — до 40 раундов. Так советуют авторы: токены он ест прилично.

  6. 06

    Читай отчёт и спрашивай жителей

    После симуляции MiroFish пишет отчёт. С любым ИИ-жителем можно поговорить: почему он против, что его зацепит.

  7. ВАЖНО

    Это симуляция, не гадалка

    Точных цифр будущего она не даёт. Используй как репетицию: какие вопросы зададут, на что разозлятся, что поправить до запуска.
